# Huella Viva

Sitio de **Huella Viva**, organización sin fines de lucro nacida como proyecto de colegio sobre **tenencia responsable de animales**.

## Cómo verla

```bash
cd tenencia-responsable
npm install
npm run dev
```

Abrí la URL que muestra Vite (por defecto `http://localhost:5173`).

## Qué podés corregir fácil

Casi todo el texto está en `src/content.ts`:

- nombre de la ONG
- mail, Instagram, ciudad
- misión, visión y valores
- pilares y decálogo
- programas y formas de ayudar

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- lucide-react
